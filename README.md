# Data Cleaner AI

A Python script that intelligently cleans messy data using Claude-inspired logic patterns.

## 🎯 Features
- Reads unstructured/messy data from `input.txt`
- Cleans and structures the data
- Outputs clean CSV format
- Simple and easy to use

## 🚀 How to Use

### Prerequisites
```bash
pip install -r requirements.txt
```

### Run the Script
```bash
python clean_data.py
```

### Input Format
Add your messy data to `input.txt`, for example:
Osama alkhaldy, 24 years

The script generates clean CSV output:

- `clean_data.py` - Main Python script
